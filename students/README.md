# PHOENIX Student Management

ماژول مدیریت شاگردان فونیکس برای ثبت، پیگیری و تحلیل مسیر آموزشی.

## اصول
- اطلاعات واقعی شاگردان در مخزن عمومی GitHub ذخیره نشود.
- GitHub فقط کد، ساختار داده، قالب‌ها و مستندات غیرحساس را نگهداری می‌کند.
- برای هر شاگرد یک شناسه یکتا (`student_id`) استفاده شود.
- اطلاعات قابل توسعه برای آینده طراحی شده است.

## حوزه‌های ثبت
1. مشخصات فردی و راه‌های ارتباطی
2. تاریخ شروع آموزش و وضعیت فعلی
3. دوره/مسیر آموزشی و اهداف
4. پرداخت‌ها و وضعیت مالی
5. جلسات و حضور و غیاب
6. ارزیابی پیشرفت و نقاط قوت/ضعف
7. کتاب‌های توصیه‌شده و وضعیت مطالعه
8. تکالیف و اقدامات بعدی
9. یادداشت‌های مربی
10. سوابق تغییرات و پیگیری

## ساختار
- `schema/student.schema.json` ساختار استاندارد پرونده شاگرد
- `templates/student-record.template.json` قالب خالی ثبت شاگرد
- `PRIVACY.md` سیاست نگهداری اطلاعات

این ماژول باید در ادامه به لایه حافظه و داشبورد فونیکس متصل شود.
