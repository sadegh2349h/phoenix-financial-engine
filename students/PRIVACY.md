# حریم خصوصی اطلاعات شاگردان

این مخزن عمومی است؛ بنابراین **اطلاعات واقعی و شخصی شاگردان نباید مستقیماً در GitHub ذخیره شود**.

### اطلاعات ممنوع در مخزن عمومی
- نام و نام خانوادگی واقعی
- شماره تلفن و ایمیل
- تاریخ تولد
- اطلاعات پرداخت و مبالغ دریافتی واقعی
- آدرس و اطلاعات تماس اضطراری
- یادداشت‌های خصوصی مربی
- هر داده‌ای که بتواند هویت فرد را مشخص کند

### الگوی پیشنهادی
GitHub: کد + ساختار + قالب خالی + مستندات

حافظه خصوصی فونیکس/پایگاه داده امن: اطلاعات واقعی شاگردان

هر اتصال آینده به داشبورد باید احراز هویت، سطح دسترسی و ثبت سابقه تغییرات داشته باشد.
