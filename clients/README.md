# Phoenix Clients

This directory stores structured, non-sensitive client project records for PHOENIX.

## Purpose
- Preserve project decisions and approved outputs.
- Track client status and next actions.
- Prevent loss of project context.
- Keep client-specific information separated from PHOENIX core code.

## Privacy rule
This repository is public. Do not store passwords, API keys, private credentials, medical records, private financial details, or other sensitive personal data here.
