# PHOENIX Social Public Data Route

## هدف
ایجاد مسیر عملیاتی برای تحلیل URL عمومی شبکه‌های اجتماعی بدون ادعای دسترسی به داده خصوصی.

## اصل دسترسی
- داده عمومی فقط از منبعی استفاده می‌شود که دسترسی آن مجاز و قابل اتکا باشد.
- Insights و داده‌های خصوصی فقط با اتصال رسمی و مجوز صاحب حساب دریافت می‌شوند.
- هیچ رمز عبور، دور زدن محدودیت، یا استخراج غیرمجاز انجام نمی‌شود.

## مسیر عملیاتی
URL → acquisition adapter → normalized evidence → social intelligence → business diagnosis → specialist routing → human decision.

## وضعیت
قرارداد اتصال در `phoenix_core/social_acquisition_layer.py` آماده است و adapter تزریقی را پشتیبانی می‌کند. این سند مشخص می‌کند که لایه دریافت داده عمومی باید به یک منبع مجاز متصل شود و نباید به‌صورت مصنوعی داده بسازد.

## معیار پذیرش
1. URL معتبر پذیرفته شود.
2. منبع داده و سطح مجوز ثبت شود.
3. هر فیلد تحلیل‌پذیر دارای evidence باشد.
4. داده ناموجود هرگز حدس زده نشود.
5. تحلیل نهایی شامل confidence و نیاز به بازبینی انسانی باشد.
