# مهارت ویرایش ویدئوی فونیکس

منبع: https://github.com/kajisho5/ffmpeg-skill
مجوز: MIT
نسخه ثبت‌شده: `432cc1b39becf3751284204441bcc7048b07139e`

## دریافت زیرمخزن
هنگام clone کردن مخزن فونیکس از گزینه `--recurse-submodules` استفاده کنید. برای مخزن موجود، `git submodule update --init --recursive` را اجرا کنید.

## پیش‌نیازها
- FFmpeg نسخه ۶٫۱ یا جدیدتر و FFprobe
- Python نسخه ۳٫۱۰ یا جدیدتر
- برای رونویسی خودکار گفتار، موتور تشخیص گفتار محلی جداگانه لازم است.

## اصول استفاده
1. فایل اصلی بازنویسی نشود؛ خروجی در فایل جداگانه ذخیره شود.
2. مشخصات فایل قبل از ویرایش بررسی شود.
3. ابتدا اجرای آزمایشی بدون تولید خروجی انجام شود.
4. پس از ویرایش، مشخصات فنی و تصویر خروجی بررسی شود.
5. تا زمانی که آزمون واقعی انجام نشده، خروجی تأییدشده اعلام نشود.

ثبت زیرمخزن در کد فونیکس، نصب پیش‌نیازها و اجرای آزمون روی دستگاه را خودکار انجام نمی‌دهد؛ این موارد باید جداگانه بررسی شوند.
