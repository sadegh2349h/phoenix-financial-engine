# PHOENIX Client Intelligence Operating Loop

## استاندارد اجرایی

`ورود مشتری → اطلاعات و مجوز → داده مجاز → خط مبنا → تحلیل → گلوگاه → فرصت → اقدام → تأیید انسانی → اجرا → پایش → گزارش → یادگیری`

## وضعیت‌های عملیاتی

- `needs_setup`: اطلاعات یا مجوز ناقص است.
- `ready_for_analysis`: اطلاعات پایه و مجوز آماده است.
- `analysis_complete`: تحلیل شواهد‌محور انجام شده است.
- `awaiting_human_approval`: پیشنهادها آماده تصمیم انسانی هستند.
- `action_active`: اقدام تأییدشده در حال اجراست.
- `measurement_due`: زمان سنجش نتیجه رسیده است.
- `learning_ready`: نتیجه برای ثبت در حافظه آماده است.

## قوانین

1. بدون مجوز داده، تحلیل اجرا نمی‌شود.
2. قبل از توصیه، خط مبنا ثبت می‌شود.
3. پیشنهادها باید قابل توضیح و قابل سنجش باشند.
4. PHOENIX تصمیم نهایی کسب‌وکار را جایگزین انسان نمی‌کند.
5. نتیجه هر اقدام با KPI (شاخص کلیدی عملکرد) مقایسه می‌شود.
6. یادگیری فقط از نتیجه داده و اقدام مجاز ساخته می‌شود.
7. اتصال به شبکه‌های اجتماعی و CRM فقط از مسیرهای مجاز و API (رابط برنامه‌نویسی کاربردی) رسمی/تأییدشده انجام می‌شود.

## خروجی استاندارد مشتری

`خلاصه مدیریتی → وضعیت فعلی → داده و مجوز → خط مبنا → گلوگاه → شواهد → فرصت‌ها → اقدام پیشنهادی → KPI هدف → نتیجه واقعی → یادگیری → گام بعدی`

این لایه، استفاده از قابلیت‌های هوش مشتری فونیکس را برای هر مشتری تکرارپذیر، قابل سنجش و قابل کنترل می‌کند.
